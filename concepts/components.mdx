Mintlify ships a library of ready-made MDX components you can drop into any `.mdx` page. They handle styling, dark mode, and responsive layout automatically — no imports, no configuration, no custom CSS. You write the content; the components handle how it looks.

## Using Components

Components are available globally in every `.mdx` file — **no import statement needed**. Use them exactly as you'd write JSX, directly alongside your Markdown prose:

```mdx
Regular Markdown content works exactly as you'd expect, and you can
mix in components anywhere on the page.

<Note>
  This is a note callout. Use it to highlight information readers
  should keep in mind before moving on.
</Note>

You can also nest Markdown inside components. The sentence above
and this paragraph are both plain Markdown.
```

A `<Card>` with a link, an icon, and a description looks like this:

```mdx
<Card
  title="Quickstart"
  icon="rocket"
  href="/quickstart"
>
  Get your first Mintlify site live in under five minutes.
</Card>
```

Both of those examples render into fully styled, theme-aware components with zero additional setup.

## Quick-Reference Examples

Here are the components you'll reach for most often:

**Callouts**

```mdx
<Note>Something the reader should know, but won't break anything if missed.</Note>

<Tip>A helpful shortcut or best practice worth highlighting.</Tip>

<Warning>Something that could cause data loss, downtime, or unexpected behavior.</Warning>

<Info>Neutral supplementary context that doesn't fit in the flow of prose.</Info>
```

**Steps**

```mdx
<Steps>
  <Step title="Install the CLI">
    Run `npm i -g mintlify` to install the Mintlify CLI globally.
  </Step>
  <Step title="Start the dev server">
    Run `mintlify dev` from your docs root to preview changes locally.
  </Step>
  <Step title="Push to deploy">
    Commit and push to your default branch — Mintlify deploys automatically.
  </Step>
</Steps>
```

**Tabs**

Use `<Tabs>` and `<Tab>` for platform-specific or language-specific alternatives. Each `<Tab>` takes a `title` prop and contains freeform content — including code blocks:

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @acme/sdk
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add @acme/sdk
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add @acme/sdk
    ```
  </Tab>
</Tabs>
