sidebarTitle: "Authentication"

---

The Mintlify API authenticates requests using API keys passed as bearer tokens. Every request to the API must include your API key in the `Authorization` header. Requests made without a valid key are rejected with an HTTP `401` response.

## Get your API key

<Steps>
  <Step title="Log in to your dashboard">
    Go to [dashboard.mintlify.com](https://dashboard.mintlify.com) and sign in to your account.
  </Step>
  <Step title="Open API Keys settings">
    Navigate to **Settings** → **API Keys** in the left sidebar.
  </Step>
  <Step title="Generate a new key">
    Click **Generate new key** and give it a descriptive name — for example, `CI/CD Pipeline` or `Content Sync Script`.
  </Step>
  <Step title="Copy the key">
    Copy the key immediately after it is generated. For security reasons, it will only be shown once. If you lose it, you will need to generate a new one.
  </Step>
</Steps>

## Using your API key

Pass your API key as a bearer token in the `Authorization` header on every request:

```bash
curl https://api.mintlify.com/v1/deployments \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Python example

```python Python
import requests

headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

response = requests.get(
    "https://api.mintlify.com/v1/deployments",
    headers=headers
)
print(response.json())
```

## Error responses

If your API key is missing or invalid, the API returns HTTP `401 Unauthorized` with the following response body:

```json
{
  "error": {
    "code": "unauthorized",
    "message": "Invalid or missing API key."
  }
}
```

Check that you have copied the full key correctly and that it has not been revoked in your dashboard.

<Warning>
  Keep your API key secret. Do not commit it to version control or embed it directly in your source code. Store it as an environment variable — for example, `MINTLIFY_API_KEY` — and read it at runtime instead.
</Warning>
